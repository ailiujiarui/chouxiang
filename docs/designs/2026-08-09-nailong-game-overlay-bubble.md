# 奶龙游戏内气泡显示设计

日期：2026-08-09
状态：已实施，code review 通过

## 问题

游戏吐槽可以在连续游戏 5 分钟后生成，但当前全屏门禁会阻止所有通知租约。
因此通知只会保持 `PENDING`，用户在游戏过程中看不到气泡。

## 方案

- 仅当用户开启“游戏中允许轻微吐槽”时，允许 `LIGHT_TEASE` 类型通知越过全屏门禁。
- 编码鼓励、调试提示、测试结果和其他通知仍受全屏门禁保护，不在游戏画面上弹出。
- 游戏气泡继续保持低优先级、每次连续游戏会话最多一次、12 秒自动关闭，并允许用户手动关闭。
- 渲染失败必须 ACK `FAILED`；实际绘制后才 ACK `SHOWN`，不提前消耗或伪报可见状态。
- 边框无窗口全屏游戏使用桌宠置顶气泡显示；独占全屏无法保证覆盖时，保留通知为 `PENDING`，不循环重试刷屏。
- 不增加截图、OCR、窗口标题保存、键盘钩子或游戏内容读取。

## 实现边界

- 投递门禁需要按通知类型判断，不能简单关闭全局全屏保护。
- 渲染层不调用 LLM，只接收已生成的 `PopupDecision`。
- 保留免打扰、手动暂停、冷却、每日预算和隐私授权。

## 验收

- 开启游戏吐槽后，边框无窗口全屏游戏内能看到一次轻微吐槽。
- 普通通知在全屏游戏中仍保持 `PENDING`。
- 关闭游戏吐槽后，全屏游戏中不生成也不显示吐槽。
- 完整测试、编译检查和 diff 检查通过。

## 实施结果

- 全屏状态下使用原子 SQL 筛选，只租约 `LIGHT_TEASE` 且来源为 `game-session:*` 的游戏会话通知。
- 普通通知继续保持 `PENDING`，不会消耗弹窗预算，也不会被误标记为已显示。
- 游戏吐槽开关关闭时，尚未显示的游戏会话吐槽会被标记为 `DISMISSED`，退出全屏后不会补弹。
- PySide6 气泡继续使用置顶、无焦点窗口；首次绘制后才 ACK `SHOWN`，渲染异常 ACK `FAILED`。
- 验证结果：`607 passed, 11 skipped`；`compileall` 与 `git diff --check` 通过。
