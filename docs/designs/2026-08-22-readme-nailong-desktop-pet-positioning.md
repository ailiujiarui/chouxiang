# README 奶龙桌宠定位更新设计

日期：2026-08-22  
状态：待确认

## 目标

将 README 的产品首要定位从“代码审判助手”更新为“奶龙桌宠”，同时保留代码评测、活动监听、隐私和 DeepSeek 配置等真实能力说明。

## 核心表达

- 奶龙是常驻 Windows 桌面的轻量陪伴型桌宠，不是 Dashboard 浮层，也不是单纯通知器。
- “抽象”来自它的行为和表达：用纯文字眼睛、嘴巴、状态气泡和中度傲娇口吻表达观察、吐槽、提醒、庆祝与安静；不依赖复杂动画资源。
- 它会根据本地活动状态决定是否说话，遵守冷却、免打扰、暂停、全屏和隐私授权规则。
- 检测到已保存的 Python 文件且用户明确授权后，才会调用真实 DeepSeek 做静态评测，并以奶龙气泡输出简短、带态度但基于证据的报告。

## README 调整范围

1. 顶部标题和简介改为奶龙桌宠定位。
2. 增加“奶龙是什么/哪里抽象”小节，描述文字表情、状态气泡、傲娇回应和不打扰原则。
3. 将一键启动、设置、拖动、监听授权和自动 Python 评测放到产品主流程中。
4. 保留代码审判 API、CLI、DeepSeek、隐私和许可证章节，但明确它们是奶龙背后的分析能力或开发者接口。
5. 不虚构 PNG/GIF/动画资源，不宣称会读取未保存代码、剪贴板、截图或终端正文。

## 验收标准

- 用户打开 README 首屏即可理解项目是奶龙桌宠。
- “抽象”描述具体可感知，不使用空泛的营销词。
- 启动、授权、评测、隐私边界与当前实现一致。
- 代码审判能力仍可被开发者通过 README 找到。
